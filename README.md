# IMPACT LAB 3D

**[실험실 열기](https://kosang02.github.io/Gpt_and_claude/)**

강판의 입체 변형·파단을 관찰하는 Three.js 기반 교육·게임용 샌드박스입니다. 단위는 실험실의 임의 단위이며 실제 탄약, 장갑 또는 재료의 성능을 계산하지 않습니다.

## 사용법

1. 강판을 클릭하거나 터치해서 충돌 위치를 선택합니다. 드래그는 카메라 회전, 휠·두 손가락은 확대/이동입니다.
2. AP 형상체, 강철 구체, 성형작약을 모티브로 한 가상 제트를 선택하고 충격 강도를 조절합니다.
3. **충돌 실험** 또는 Space로 발사합니다. 낮은 강도에서는 함몰, 높은 강도에서는 불규칙한 구멍과 말린 가장자리를 관찰할 수 있습니다. 기울기가 큰 표면에는 도탄이 발생할 수 있습니다.
4. **앞면 / 측면 / 뒷면**으로 돌아보거나 **단면**에서 강판의 두께와 굽힘을 확인합니다. 단면은 조준 위치에서 절단한 관찰 모드이며, 발사 시 전체 강판으로 복원됩니다.
5. **Ⅱ**로 일시정지하고 **▹|**로 시뮬레이션 시간 1/60초씩 진행합니다. 1×, 0.25×, 0.08× 속도를 선택할 수 있습니다. 일시정지 중에도 카메라는 움직입니다.
6. **＋**로 최대 6장의 강판을 추가합니다. 선택 메뉴와 이동·회전 축 또는 숫자 입력으로 배치하고 크기를 조절합니다. 추가 강판은 선택 강판 뒤에 배치됩니다. 발사체는 실제 경로에서 먼저 만나는 표면에 충돌합니다.
7. **장면 저장**은 현재 브라우저의 localStorage에 강판 배치와 누적 손상을 저장합니다. 저장 시 진행 중인 변형은 완료 상태로 기록하며 발사체·파편·카메라는 저장하지 않습니다. 불러오기 전 저장하지 않은 장면은 대체됩니다.

강판 복원은 선택한 강판의 손상만 지웁니다. 전체 초기화는 배치, 손상, 파편과 실험 기록을 초기화하며 저장 슬롯은 유지합니다.

## 파괴 모델

- 앞·뒷면을 갖는 불규칙한 삼각 격자, 외곽 및 구멍의 경계를 연결한 절단면으로 강판의 부피를 표현합니다.
- 충돌 주변의 국소 함몰, 넓은 굽힘, 방사형 찢김, 말린 파단부, 변색을 시간에 따라 적용합니다.
- 손상은 누적되며 기존 변형 근처의 후속 충격에 영향을 줍니다. 이미 열린 구멍은 실제로 비어 있어 새 충돌을 만들지 않고 통과할 수 있습니다.
- 매 프레임 발사체 이동 구간을 강판 메시와 교차 검사하는 swept ray로 충돌을 감지합니다. 판정에 입사 방향을 사용하며 강판 회전과 발사 방향은 독립적입니다.
- 파편은 개별 속도·회전·중력·바닥 반발을 갖고 착지 후 일정 시간 남습니다. 최대 300개 효과와 동시 8개 충돌체로 제한합니다.
- 가상 제트는 발사체 접근 → 국소 발광/충격환 → 짧은 제트 → 작은 파단으로 구분합니다.

**한계:** 소성 변형과 균열은 절차적 시각화이며 유한요소법, 응력파, 파괴역학, 에너지·질량 보존 해석이 아닙니다. 발사체는 유한 반경 강체 대신 선분으로 충돌 검사합니다. 파편은 바닥에만 충돌하며 강판이나 다른 파편과 충돌하지 않습니다. 메시 관통 깊이나 구멍 크기는 실제 성능을 의미하지 않습니다. 큰 손상의 중첩에서는 메시가 서로 겹칠 수 있습니다.

## 실행과 배포

빌드와 백엔드가 없는 정적 사이트입니다. 외부 CDN이나 웹폰트 요청 없이 로컬 파일만으로 실행됩니다.

```sh
npm start
# http://localhost:4173
```

GitHub Pages 설정: `main` 브랜치, 저장소 루트 `/`. `main`에 push하면 Pages가 배포합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

```text
index.html                    UI 구조와 로컬 import map
src/main.js                   장면·발사·저장·시간 관리
src/style.css                 반응형 인터페이스
src/scene/                    조명·환경·카메라
src/objects/                  두께가 있는 강판·발사체
src/physics/                  변형 필드·파단 위상·구간 충돌
src/effects/                  파편·먼지·불꽃·가상 제트
src/ui/                       조작·상태·실험 기록
vendor/                       Three.js 0.160.1 및 부속 모듈 / MIT
```

## 검증

```sh
npm test
# 별도 터미널에서 npm start 후:
python -m pip install playwright
python -m playwright install --with-deps chromium webkit
python tests/browser_check.py
python tests/browser_regression.py
```

`?debug=1`일 때만 `window.impactLab`을 노출하여 브라우저 회귀 검사에서 재현 가능한 시간 진행과 메시 상태 검사가 가능합니다. 테스트 이미지와 임시 결과는 `artifacts/`에 저장하며 커밋하지 않습니다. `LAB_URL`로 배포 사이트도 검사할 수 있습니다.

브라우저 검증 범위와 기기 한계는 [검증 기록](VALIDATION.md)을 참고하세요. 실제 iPhone Safari 검증은 Linux WebKit의 모바일 에뮬레이션과 구분합니다.
